## 0.1.0

The first public release is available from npm under the `@maelstrom-co` scope.
It includes the protocol, framework-independent client, React bindings, Engine,
planners, development tools, and optional voice packages.

Install matching package versions. `@maelstrom-co/react` includes the client and
protocol dependencies needed for a React application. A model-backed application
also needs a server-side planner and an Engine host.

See the [0.1.0 release notes](https://github.com/maelstrom-co/maelstrom/releases/tag/v0.1.0)
for the published release and [installation](/getting-started/installation/) for
the package choices.

## Upgrading

The SDK is in the 0.x series. Read each release's notes before upgrading; a public
non-prerelease version does not promise that future 0.x releases preserve every
API. Follow the [GitHub releases](https://github.com/maelstrom-co/maelstrom/releases)
for subsequent changes.
