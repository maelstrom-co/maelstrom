## Packages

Maelstrom is distributed as a set of scoped packages:

| Package | Purpose |
|---------|---------|
| `@maelstrom-co/react` | React bindings — `createMaelstrom()`, `vessel()`, hooks, components |
| `@maelstrom-co/client` | Framework-agnostic client — Orchestrator, connectors, managers |
| `@maelstrom-co/protocol` | Shared types, Zod schemas, message definitions |
| `@maelstrom-co/engine` | Server-side LLM decision engine |
| `@maelstrom-co/voice` | Voice capture, playback, VAD (optional) |
| `@maelstrom-co/voice-server` | Backend voice runtime for STT, engine handoff, and TTS (optional) |

## Install

Most applications need `@maelstrom-co/react` (which includes `client` and `protocol` as dependencies) and `@maelstrom-co/engine` for the server:

<Tabs>
  <TabItem label="npm">
  ```bash
  # Client-side
  npm install @maelstrom-co/react

  # Server-side
  npm install @maelstrom-co/engine
  ```
  </TabItem>
  <TabItem label="bun">
  ```bash
  # Client-side
  bun add @maelstrom-co/react

  # Server-side
  bun add @maelstrom-co/engine
  ```
  </TabItem>
  <TabItem label="pnpm">
  ```bash
  # Client-side
  pnpm add @maelstrom-co/react

  # Server-side
  pnpm add @maelstrom-co/engine
  ```
  </TabItem>
</Tabs>

## Peer dependencies

`@maelstrom-co/react` requires:
- `react` >= 18.0.0
- `react-dom` >= 18.0.0

## Environment variables

The Engine requires an LLM provider API key:

```bash
# .env
GOOGLE_GENERATIVE_AI_API_KEY=your-key  # Google Gemini
OPENAI_API_KEY=your-key                # OpenAI
ANTHROPIC_API_KEY=your-key             # Anthropic Claude
```

<Aside type="tip">
  Only one LLM provider key is needed. Choose whichever provider you prefer.
</Aside>

## Voice (optional)

For browser voice features, install the voice package:

```bash
npm install @maelstrom-co/voice
```

For full end-to-end voice, also install the backend runtime package:

```bash
npm install @maelstrom-co/voice-server
```

<Aside type="caution">
  The voice package includes `onnxruntime-web` and model/runtime assets, which is why it's a separate optional package. Final download size varies by bundling and deployment setup.
</Aside>

## Voice Integration

Full end-to-end voice integration needs both the browser-side packages and the backend runtime package. Install `@maelstrom-co/react-voice` and `@maelstrom-co/voice` in the app that captures microphone input and plays speech, then install `@maelstrom-co/voice-server` in the backend that runs the STT, engine, and TTS pipeline.

| Package | Role | Install |
|---------|------|---------|
| `@maelstrom-co/react-voice` | React extension that adds `useVoice()` and `VoiceOrb` to a Maelstrom instance | `bun add @maelstrom-co/react-voice` |
| `@maelstrom-co/voice` | Browser voice runtime for audio capture, playback, and VAD | `bun add @maelstrom-co/voice` |
| `@maelstrom-co/voice-server` | Server runtime that orchestrates STT, engine processing, and TTS output | `bun add @maelstrom-co/voice-server` |

If you only install the browser packages, you can build the client-side voice controls, but you still need `@maelstrom-co/voice-server` or an equivalent backend runtime to complete the full browser-to-server voice flow.
