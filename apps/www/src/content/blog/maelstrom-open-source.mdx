Maelstrom is a framework that lets AI rearrange your app's interface and act
inside it as people work. It uses the components your team has built, from a
calendar to a task list.

We're releasing Maelstrom as open source under the MIT license. Version 0.1.0
is available now, and you can explore the [code on GitHub](https://github.com/maelstrom-co/maelstrom).

## An interface that follows the task

Imagine a planning app. A user asks to see their tasks beside their calendar,
then asks to add a task. Maelstrom lets the model arrange those components on
screen and run the task list's add action.

As the user moves to the next task, the interface can change with them. People
can also use the same buttons and controls to make changes themselves.

Developers define which components AI can use, how each can appear, and which
actions it can run. Your team controls the design and behavior of those
components.

Maelstrom is designed for apps where the useful layout depends on what someone
is trying to do, such as dashboards and workspaces with several tools.

## Start building

If you already have an app, use our [guided setup](/#get-started). Copy the
integration prompt into your coding agent. It asks what you want to build,
looks at your project, and helps you plan a small first integration. You review
the plan before making changes.

You can also install the [Maelstrom skills](https://docs.maelstrom-ai.co/agents/skills/)
to give your coding agent guidance for setup and later development tasks.
The entry skill asks whether you're starting fresh or working in an existing app.

For a new project, clone the [React starter](https://github.com/maelstrom-co/react-starter)
and follow the [run guide](https://docs.maelstrom-ai.co/getting-started/starter/).
It includes a working app and local server. The first example uses a fixed
response, so you can run it without a model API key. The guide also explains
how to connect a model when you're ready.
