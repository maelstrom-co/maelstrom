# @maelstrom/client

Framework-agnostic client core for Maelstrom.

This library provides the core client-side functionality for Maelstrom applications, including:
- Buoy registration and management
- Chart state management
- Server connection and communication
- Event bus for buoy orchestration

## Building

Run `nx build core` to build the library.

## Running unit tests

Run `nx test core` to execute the unit tests via [Vitest](https://vitest.dev/).
