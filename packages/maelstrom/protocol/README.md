# @maelstrom/protocol

Client-server communication protocol for Maelstrom.

This library defines the WebSocket protocol and message formats for communication between:

- Client and Server
- Buoys and Maelstrom
- State synchronization

## Building

Run `nx build protocol` to build the library.

## Running unit tests

Run `nx test protocol` to execute the unit tests via [Vitest](https://vitest.dev/).
