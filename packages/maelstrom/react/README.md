# @maelstrom/react

React bindings for Maelstrom.

This library provides React-specific components and hooks:
- `<MaelstromProvider>` - Context provider
- `<Chart>` - Canvas component for buoys
- `<Buoy>` - Wrapper component for buoys
- `useMaelstrom()` - Hook for buoys to communicate
- `useRegisterBuoy()` - Hook to register buoy metadata

## Running unit tests

Run `nx test @maelstrom/react` to execute the unit tests via [Vitest](https://vitest.dev/).
