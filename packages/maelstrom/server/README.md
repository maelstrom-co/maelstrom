# @maelstrom/server

Server-side orchestration for Maelstrom.

This library provides the server-side components for Maelstrom:
- AI model integration (via Vercel AI SDK)
- Conversation flow management
- Buoy orchestration logic
- WebSocket server implementation

## Building

Run `nx build server` to build the library.

## Running unit tests

Run `nx test server` to execute the unit tests via [Vitest](https://vitest.dev/).
