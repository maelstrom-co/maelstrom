# @maelstrom/types

Shared TypeScript types and interfaces for Maelstrom.

This library contains all shared type definitions used across Maelstrom packages:
- Buoy definitions and schemas
- Chart state types
- API interfaces
- Event types

## Building

Run `nx build types` to build the library.

## Running unit tests

Run `nx test types` to execute the unit tests via [Vitest](https://vitest.dev/).
