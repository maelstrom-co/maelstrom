# @maelstrom-co/voice-server

Backend voice runtime for Maelstrom. This package orchestrates speech-to-text (STT), handoff into the engine, and text-to-speech (TTS) for end-to-end conversational voice flows.

## Install

```bash
bun add @maelstrom-co/voice-server
```

For full voice integration, pair this server package with the browser-side packages in your client app:

```bash
bun add @maelstrom-co/react-voice @maelstrom-co/voice
```
